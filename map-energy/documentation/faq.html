Tesla Powerwall Backup Reserve Limits

MAP Energy Support

Tesla places restrictions on the backup reserve percentages that can be configured for a Powerwall. These restrictions also apply when MAP Energy changes the backup reserve through an automation.

What backup reserve values can be used?

Tesla currently allows the Powerwall backup reserve to be set to:

  • Any value from 0% to 80%
  • 100%

Backup reserve values between 81% and 99% are not supported by Tesla.

Important: If a backup reserve between 81% and 99% is requested, Tesla may limit or adjust the requested value rather than maintaining that reserve percentage.

Why does MAP Energy have this restriction?

This is a Tesla Powerwall restriction rather than a limitation introduced by MAP Energy.

MAP Energy communicates with your Powerwall through Tesla's services, so changes made by an automation must use values that Tesla currently accepts.

How does this affect MAP Energy automations?

Automations that use the Adjust Backup Reserve action should use a reserve of 80% or below, or 100%.

For example:

  • Setting the backup reserve to 20% is supported.
  • Setting the backup reserve to 80% is supported.
  • Setting the backup reserve to 90% is not supported.
  • Setting the backup reserve to 100% is supported.

Using 100% backup reserve

Setting the backup reserve to 100% can be useful when you want to prevent the Powerwall from supplying normal household demand.

MAP Energy automations can therefore temporarily set the reserve to 100% and later return it to another supported value.

Existing automations

If you created an automation using a backup reserve between 81% and 99%, we recommend editing it and selecting either:

  • 80% or lower; or
  • 100%.

This helps ensure the automation behaves consistently with Tesla's current Powerwall controls.

Need help?

If an automation is not changing your Powerwall backup reserve as expected, check the automation history in MAP Energy first. This can help confirm whether the action was successfully sent to Tesla.

You can also contact MAP Energy support if you need help diagnosing an automation or Powerwall control issue.
